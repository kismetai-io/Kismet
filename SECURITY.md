# Security reports

Send a private report to legal@kismetai.io. Include the affected version,
reproduction steps and impact. Do not include real credentials, customer data
or private Blueprint contents. Do not post an exploit against the account
or registry service in a public issue before maintainers have assessed it.

Local HTTP authentication and browser-origin checks protect the editor service.
Kismet account credentials authorize account and registry operations separately;
model requests use the user's provider credentials. A skill bundle
contains instructions and text resources, declares permitted tools, and cannot
install executable extensions. Inspect a skill and its permissions before use.

A revoked registry version cannot be downloaded again. Installed local files
remain under the user's control; registry availability does not delete them.
